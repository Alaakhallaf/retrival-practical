### 🧠 Implemented Algorithms & CS Concepts

- 📐 **Vector Space Model (VSM):** Converts textual tokens into multi-dimensional vectors in space to calculate spatial proximity and semantic similarity between search queries and documents.
- 📉 **Cosine Similarity & Term Weighting:** Evaluates document relevance based on vector angular distances.
- 🧮 **Distance & Error-Correction Matrix (Edit Distance / Levenshtein):** Computes step-by-step edit operations between misspelled terms and index vocabulary to suggest "Did you mean...?" queries.
- 🖥️ **Console & GUI Output:** Deep algorithmic metrics and execution calculations are output directly to the **Browser Console**, paired with a functional UI for query input and document visualization.
